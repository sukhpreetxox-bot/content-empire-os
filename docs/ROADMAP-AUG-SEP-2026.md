# Roadmap — Aug → Sep 2026 (autonomous run)

Goal: run Quiet Capital hands-off through end of September, doubling down only on
what the data proves works, and grow toward the first 1,000 subs.

## What the data says works (our own retention cohort)

Clean signal = average view duration. Winners hold 50–59s on a ~25s Short →
viewers **loop/rewatch**. Losers bail at 4–9s.

- **Winners (keep):** paradox / reframe / "invisible X" framings that deliver a
  complete, looping thought. e.g. *The Paradox of Emotional Resilience* (36 views,
  140% ret), *The Invisible Labor of Stillness* (109%), *Motivation Is a Wake* (185%).
- **Losers (drop):** thin tech-panic clickbait that over-promises and under-delivers.
  e.g. *Your Unread Messages Are Attacking Your Nervous System* (10 views but **12%**
  ret), *Your Screen Isn't Free* (17%). Good title, no payoff → viewers feel tricked.

**Rule for the whole run:** the title makes a promise; the body must pay it off and
loop. Reach without retention is worthless.

## Market research (Aug 2026) — validated

- Slower, meditative voice-over + cinematic visuals → more watch time. *(we run
  am_onyx at 0.90 speed — already there.)*
- Controversial/contrarian spin stops the scroll better than plain advice. *(our
  reframe titles align.)*
- Volume matters for faceless: 1–3 Shorts/day; 12+/month = 66% more subs; faceless
  needs 2–3× the volume of face channels. → **2/day.**
- Marcus Aurelius / Seneca quote-anchored content performs. *(seeded into ideas.)*
- Realistic: 0→1k in the first growth phase with daily posting; 3–6 months to 10k.

This needs **zero manual steps** to run through September.

## 3-week plan (Aug)

- **Week 1** — Let the new engine run: 2/day, auto-publish, retention-tuned Shorts
  (hook formulas, 18–28s, faster cuts) draining the curated inbox. Baseline the
  new cohort's retention vs the old (~39%).
- **Week 2** — First read: which framings/themes retain >70%? Analytics keeps
  seeding winner-echoes. If retention climbs, hold course. If a theme collapses
  (e.g. over-indexing on "motivation"), broaden the inbox.
- **Week 3** — Restock the inbox (~2 weeks used up). Prune any framing that keeps
  landing <40%. Double down on the top-3 retaining framings.

## Through September

- Repeat the weekly loop: measure → keep winners → restock → prune losers.
- Re-stock the ideas inbox roughly every 2 weeks (or the analytics winner-echo
  carries it). If the inbox empties, generation falls back to keyword trends —
  acceptable but weaker, so keep it fed.
- **Gate to re-enable deep long-form:** only once Shorts average ≥60% retention
  AND subs are climbing. Deep = watch-time/revenue, pointless before an audience.
- **Still outside the pipeline (owner's call, not a code fix):** channel branding
  (avatar/@handle/About) and distribution/cross-post — the real reach lever,
  deliberately deferred.

## Check-in triggers (when to intervene)

- Retention of the new cohort stays <40% after Week 1 → the hook/body needs a
  sharper pass, not more volume.
- One theme dominates >60% of output → broaden the inbox.
- A generate/publish run fails repeatedly → token or quota issue (see HANDOFF §3).

## Honest note

The engine is now genuinely hands-off and tuned to what works. It will improve
*what* we make. It will not, by itself, create *reach* — that still needs the
distribution decision the owner is holding. Autonomy buys consistency, not virality.
